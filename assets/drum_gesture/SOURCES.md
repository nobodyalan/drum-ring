# Drum Gesture Sound Sources

Gesture sounds are stored in `sounds/` with stable filenames used by the app.

## Mapping

- `1` 踩镲: `gesture_1_closed_hat.wav`
- `2` 通鼓2: `gesture_2_tom2.wav`
- `3` 军鼓: `gesture_3_snare.wav`
- `4` 通鼓1: `gesture_4_tom1.wav`
- `5` 通鼓3: `gesture_5_tom3.wav`
- `6` 吊镲: `gesture_6_crash.wav`
- `7` 节奏镲: `gesture_7_ride.wav`

## Final Sources

The active files in `sounds/` use BigSoundBank samples converted from MP3 to WAV:

- Close hi-hat: https://bigsoundbank.com/hi-hat-close-6-s2301.html
- Medium tom: https://bigsoundbank.com/medium-tom-3-s2335.html
- Snare drum: https://bigsoundbank.com/snare-drum-4-s2307.html
- High pitched tom: https://bigsoundbank.com/high-pitched-tom-1-s2329.html
- Bass tom: https://bigsoundbank.com/bass-tom-1-s2338.html
- Crash cymbal: https://bigsoundbank.com/cymbale-16-3-s2313.html
